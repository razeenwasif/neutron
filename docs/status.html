Guide

Using Neutron

Neutron works like the Finder where the Finder has an answer, and goes further with panes, a terminal, agents and a viewer. The keys follow the Finder's.

  1. Install it

    cargo xtask install builds a release and puts Neutron.app in ~/Applications.

  2. Go somewhere

    The sidebar, ⇧⌘G for a path, or drop a folder on the Dock icon.

  3. Pick a view

    ⌘1 grid, ⌘2 list, ⌘3 columns, ⌘4 gallery. Each tab keeps its own.

  4. Find anything

    ⌘P in this folder, ⇧⌘F across the Mac, ⇧⌘P for every command.

Views and layout

  • Sort and group from View: by name, kind, dates (added and last opened too) or size. Grouping works in the list and the grid.
  • Grid tile size is the slider in the grid's footer.
  • Gallery shows the current item large over a strip of thumbnails. Left and Right step along it.
  • Folder sizes: View › Calculate All Sizes, or Calculate Size on one folder. Sizes show in the list, grid and columns.
  • Split with ⌘\; drag tabs between panes. ⌃⌘S and ⌥⌘T hide the sidebar and toolbar.

Finding

  • Filter the folder with ⌘F; it clears when you leave.
  • Find a file fuzzily under this folder with ⌘P: crgtml finds Cargo.toml.
  • Search Everywhere (⇧⌘F) asks Spotlight, and takes filters: tax kind:pdf date:year tag:Red.
  • Smart Folders: File › New Smart Folder… by name or contents, kind, last changed, tag and where. Name one to keep it under Searches in the sidebar.

Working with files

  • Rename with ↩; with several selected it opens Rename Items: replace text, add text, or number them.
  • New File (⌥⌘N) makes untitled.txt; templates come from the Templates folder (see below).
  • Get Info (⌘I) is Neutron's own window, with the Finder's a click away.
  • Show Original (⌘R) on an alias or link; Put Back (⌘⌫ in the Trash).
  • Undo (⌘Z) covers copies, moves, renames, new items, Move to Trash and Put Back.
  • Tags: right-click › Tags for colours, Edit Tags… for names of your own.

Drag and drop

  • Sweep a selection box from empty space, in every view; ⌘ adds to it.
  • Drag a selected item and the whole selection goes, to Neutron or any app.
  • Drop onto a folder row, a tile, a column, a sidebar place, a tab or a folder in the path bar. The Trash trashes.
  • Hold a drag on a folder and it springs open; on a tab, the tab shows.
  • ⌥ while dropping copies; another disk copies anyway.

Terminal and agents

  • Open in Terminal (⌃`, right-click, or Go) opens your login shell in a tab, in that folder.
  • Ask Claude Code runs Claude Code there, told what was selected, accepting edits; shell commands still ask.
  • Ask Antigravity runs agy (from the Gemini app) in accept-edits mode.
  • Both agents get Neutron's search as tools: Spotlight name and full-text search, and fuzzy path matching, served by neutron --mcp.
  • Going to a folder from a terminal opens a new tab, so the shell keeps running.

Viewer, apps and archives

  • Open in Viewer (⌥⌘O) reads a PDF, an image, or text and code (coloured for about 40 languages) in a tab, with zoom and find.
  • PDFs open in Quark by double-click, through openers.json; a running Quark takes each as a tab.
  • Archives: zip, tar, tar.gz, tar.xz, tar.bz2, 7z and RAR open like folders and extract; a plain .gz unpacks beside itself.
  • Disk images (.dmg) mount and open their disk.

Where Neutron keeps things

All under ~/Library/Application Support/Neutron/ unless noted. Plain files you can read and edit.

FileWhat it holds
app.ronThe session: panes, tabs, extra windows, window sizes, and view settings (sort, group, view, tile size, hidden sidebar).
pins.json, recent.jsonPinned folders in the sidebar, and recent files.
searches.jsonSmart Folders saved to the sidebar.
openers.jsonApps chosen per extension, e.g. { "pdf": "/Applications/Quark.app" }.
trashed.jsonWhere items Neutron moved to the Trash came from, for Put Back.
Templates/Any file here appears under New File from Template.
~/Library/Caches/Neutron/archivesFiles taken out of archives to open, share or drag.
agy's MCP listAsk Antigravity adds a neutron entry there; check with agy mcp list.
